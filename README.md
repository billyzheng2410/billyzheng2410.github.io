# Jinghan Zheng — personal academic website

Live website: https://billyzheng2410.github.io/

A responsive English academic homepage with a biography, publications, research experience, portrait, and downloadable CV. Content follows the CV updated on September 16, 2026.

## Update the website

- Edit `index.html` to update the biography, publications, and research experience.
- Edit `styles.css` to change the visual design.
- Replace `assets/Jinghan-Zheng-CV.pdf` to update the CV while retaining its URL.
- Replace `assets/jinghan-zheng.jpeg` to update the portrait; adjust the image dimensions in HTML if its aspect ratio changes.

The website uses plain HTML and CSS with no installation or build step. GitHub Pages publishes the root of the `main` branch. The `.nojekyll` file keeps the files as authored.

The photograph, CV, and personal content belong to Jinghan Zheng.
